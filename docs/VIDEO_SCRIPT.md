# 7-minute video script — regime-narrative

**Polymer Tech Expo 2026.** Maximum 7 minutes. The brief requires **two parts**,
and Part 1 is not optional — an earlier draft of this script was 7:00 of project
with no self-introduction at all, which would have failed the rules outright.

Name, university, branding, AI journey and career aspiration are **filled in** —
grounded in your own repos (`purgedcv`, `pypbo`, `quantguard`) and in this
project, so every word is checkable. Two brackets remain because they are
genuinely yours: a **fun fact**, and **why Polymer specifically**. A third is
optional. Rewrite any of it in your own voice — read it aloud first; if a
sentence doesn't sound like you, change it.

Narration is pitched at ~145 wpm. Every figure is the measured value in
`outputs/`; none is rounded in your favour.

## PART 2 — Project showcase · 1:05–7:00

Required: what you built · how it works · how AI was used (coding tools, system
prompts with examples, models/APIs/platforms) · iterations and reflections.

| Time | On screen | Narration |
|---|---|---|
| **1:05–1:35**<br>(30s) | The Overview regime chart, full width — SPY on a log axis, calm bands pale blue, stressed pale red, twenty transition lines. At 1:28 one word fades in: **"Why?"** | Every regime model produces a picture like this. Calm here. Stressed here. A real statistical result, and genuinely useful. But the model only ever saw returns. It has never read a newspaper. It can tell you the market changed on this day, and nothing about why. In practice a human fills that gap from memory — undocumented, unauditable, different for every person who looks at the chart. This tool attaches an explanation to each of those lines, and then measures how much the explanation is worth. |
| **1:35–2:10**<br>(35s) | Metric tiles: per-fold median **1.52×**, sign test **p = 0.00040**, forward-20d 1.69×, transitions 20. Then `hmm_model.py` with the forward-filter function highlighted and the line where Viterbi is deliberately *not* used. | Start with the part that has nothing to do with language models. A two-state hidden Markov model on cross-asset data, refitted inside every walk-forward fold, scored only on held-out days. Of the twenty folds containing both states, eighteen show the stressed state more volatile — sign test p of four in ten thousand. I lead with that rather than the headline two-point-one-eight, because the pooled figure mixes calm years with crisis years and this one doesn't. One detail decides whether any of it is real: states are assigned by a forward filter, the probability given observations up to that day only. The standard predict call runs Viterbi over the whole sequence, so a day's label can depend on days that came *after* it. That would contaminate every transition date, and everything later rests on those dates being knowable at the time. |
| **2:10–2:45**<br>(35s) | Controls → Hindsight. **60 windows, 10,888 items, 0 post-boundary survivors.** Leak table: mean **38.2%**, max **71.2%**, the 26 Jan 2018 row highlighted. Cut to `news/base.py` — the constructor raising — then green pytest output. | The fix is to give a model the news, and only the news that existed at the time. Wikipedia's Current Events Portal, fourteen days per window, sixty windows, nearly eleven thousand items. Two things make that defensible. The boundary is structural: a window object refuses to construct if a single item post-dates it. Enforced by the type, not by a comment. And every page is pinned to its revision id. That matters more than it sounds — Wikipedia keeps editing the page for a given day for years. On average thirty-eight percent of the current page was written after the boundary. Worst case, seventy-one. The page for the twenty-sixth of January twenty-eighteen was twelve hundred bytes on the day, and was last edited in twenty-twenty-five. Fetch the live page and you feed the model hindsight, invisibly, while your manifest says the window closed on time. |
| **2:45–3:20**<br>(35s) | **REQUIREMENT: system prompts with examples.** Provenance → Prompt tab. `prompts/narrative_v1.md` with its sha256. Three highlights land in turn: the frontmatter `notes:` block; Rule 2 — *every claim must cite an item id*; Rule 4 — *you may decline*. Two-second cut to `docs/PROMPT_HISTORY.md`. | This is the system prompt. One file, version controlled, hashed, never an inline string. Three lines are load-bearing and each exists because of a specific failure mode. The frontmatter: the same prompt is used for real transitions and for control dates. An earlier draft framed controls neutrally and transitions assertively — that would have measured my framing instead of the news. It's written into the file so nobody later improves one arm. Second: every claim must cite an item id. That's not presentation, it's what makes memorisation countable — a claim whose cited item doesn't contain it is recall leaking in. Third: the model is told it may decline, and that declining is correct. Without that line it confabulates on control dates and the comparison collapses. Every decision is dated in a prompt history written as it happened, not reconstructed. |
| **3:20–3:50**<br>(30s) | **Live view, real screen recording, no cuts.** Date **2015-06-29**, tile reads **TRANSITION**. Click Run. Status log types out: items retrieved, `0` post-boundary, date scrub, "Asking claude-opus-5…". Output: **high confidence**, the Greek bailout summary, claims with green ticks and `cites …` id tags. | This is running now. I give it a date. It fetches the window, checks the boundary, strips absolute dates out of the text, and sends it. The model gets items labelled Day one to Day fourteen and nothing else. No prices. No ticker. No date. Here's what comes back — eurozone ministers refusing to extend negotiations past a deadline, a referendum called on the creditors' terms, deposit flight from Greek banks. Every sentence carries the id of the item it came from, and I can open that item and read it. |
| **3:50–4:15**<br>(25s) | **The ordinary Tuesday.** Same view, no reload. Type **2019-12-03**. Tile flips to **no transition**. Run. Output: **medium confidence**, a fluent, fully-cited US–China escalation story. Hold in silence for three seconds. | Now watch this. Third of December, twenty-nineteen. An ordinary Tuesday. The model says nothing happened. Same prompt, same pipeline, same permission to decline. And it finds a story anyway. Medium confidence, well sourced, every claim grounded. It isn't wrong — that news is real. But it isn't evidence of anything, because there is always something to point at. |
| **4:15–4:55**<br>(40s) | Controls → Blind matching. **11/20 = 55% vs 5% chance, p < 0.0001**, then the hard-negative row: **71.7% vs 33.3%**. Cut to Memorisation: **474 claims, 96.4% grounded, 1.8% random floor, 0.0% fabricated**. | So how do I tell a real explanation from generic macro commentary? Two measurements. Blind matching: strip the dates, scramble the order, and match each explanation back to its own window using held-out articles the model never saw — scored with BM25, which has no world knowledge and can't date a paragraph from training the way an LLM judge could. Fifty-five percent against one-in-twenty. And because a sceptic could say I'm only recovering roughly *when*, I re-ran it with each explanation competing against just its three nearest neighbours in time. Seventy-one point seven percent against thirty-three. Era can't explain that. Second, faithfulness: four hundred and seventy-four claims, each checked against the item it cited. Ninety-six point four percent grounded — against a one-point-eight percent floor when I score the same claims against a random article from the same fortnight. Zero fabricated citations. Not one. |
| **4:55–5:45**<br>(50s) | Controls → Placebo, full screen. Arm table held up throughout: transitions **20 / 16 / 80.0%**; all controls **40 / 26 / 65.0%**; clean **13 / 8 / 61.5%**. Then the interval: **+18.5pp, 95% CI [−12, +47]pp**, and **power 0.17**. | Here's the result that matters most, and it's the one that goes against me. Twenty real transitions, forty era-matched control dates from each transition's own neighbourhood, so the era and the news environment match. Year-mean gap of zero. Identical prompt, identical pipeline, only the news differs. On real transitions the model is confident eighty percent of the time. On clean controls, sixty-one point five. Now — the tempting thing to say is that the explanations aren't diagnostic. I can't say that. Fisher's p is zero-point-four-three, and a non-significant result is not evidence of no difference. What I can say is the interval: plus eighteen and a half points, ninety-five percent confidence from minus twelve to plus forty-seven. And the reason it's that wide is that power at the observed gap is zero-point-one-seven. This study had one chance in six of detecting the effect it actually observed. The binding constraint is twenty transitions, not the number of controls — so more placebos would not have helped. It's unresolved, and the design could never have resolved it. |
| **5:45–6:10**<br>(25s) | Cross-model table: blind match **55% / 55%**, grounding **96.4% / 96.8%**, fabricated **0 / 0**; then confidence **80% / 100%** and **κ = 0.25**. | I ran the whole thing again on a second model to see what was a property of the method and what was a property of one model. Blind matching came back identical — fifty-five percent both. Grounding differed by four tenths of a point. Zero fabricated citations in either. Those are properties of having the news and being made to cite it. But the confidence label did not replicate — kappa of zero-point-two-five window by window, and the second model declined half as often. So the absolute rates belong to the model, not the data. Which is exactly why the blind match is the load-bearing result, and why I would not build a headline on a model's opinion of itself. |
| **6:10–6:40**<br>(30s) | **REQUIREMENT: AI coding tools, models, APIs, platforms.** Full-screen card, two columns, held. **Built with:** Claude Code — code, tests, refactors; prompts hand-written and version-controlled. **Integrated:** `claude-opus-5` via the Anthropic Messages API, effort high, schema-enforced structured output · Wikipedia MediaWiki API, revision-pinned · yfinance · hmmlearn · scikit-learn · Streamlit. Cursor highlights `model: "claude-opus-5"` in `settings.yaml`. | The build. Code, tests and refactors were written with Claude Code, Anthropic's command-line agent, in this repository. The prompts were not — those are hand-written, and the reasoning behind every rule is in the prompt history. The narrative layer is claude-opus-five through the Anthropic Messages API, one call per window, no batching, with the output schema enforced server-side rather than asking the prompt nicely for valid JSON. News from the Wikipedia MediaWiki API, pinned by revision. Prices from yfinance. Statistics in hmmlearn and scikit-learn. The tool is Streamlit. The model name is one line in one settings file and appears nowhere else. |
| **6:40–7:00**<br>(20s) | **REQUIREMENT: iterations / reflections.** Back to the regime chart. Three lines fade in: *The HMM decides **when**.* / *The model describes **what was in the news**.* / *No statistic comes from the language model.* | What worked: making the boundary structural rather than a convention, and writing the controls before generating anything — including the negative controls that prove the blind-match test can fail. What I'd change: I'd pre-specify volatility *onsets* rather than all transitions, which roughly triples the power on the one test that came out unresolved. And one leak is still open — the boundary is midnight UTC, and Wikipedia reports the US close the same evening. Controls carry more of it than transitions, so it doesn't manufacture the result, but it's there and it's in the report. A method whose limit has been measured is worth more than one that has only been claimed. |
